# Property Management System (Django)

This is a Django-based DHA Property Management System developed during my internship.

## Features
- Property listing
- Vendor register
- Category management
- Image and file upload

## Tech Stack
- Python
- Django
- SQLite

## Run Project
pip install -r requirements.txt  
python manage.py migrate  
python manage.py runserver
